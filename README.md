
# TaskMate - Todo App

A responsive Todo application built with React and Vite.

## Features
- Add tasks
- Mark tasks as completed
- Filter All, Active, and Completed tasks
- Delete tasks
- Live task statistics
- Save tasks using LocalStorage
- Responsive design

## Run Locally

```bash
npm install
npm run dev
```

## Technologies
- React
- JavaScript
- CSS
- Vite
